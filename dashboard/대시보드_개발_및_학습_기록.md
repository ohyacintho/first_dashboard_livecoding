## 1. 프로젝트 개요 및 목적

### 🎯 프로젝트 배경
- **2025년 장마트(JANG MART)의 10,000건 구매 트랜잭션 데이터**와 **9회차에서 도출한 RFM 고객 가치 세그먼트 분석 결과**를 웹 대시보드로 통합 구축.
- 단순한 차트 나열을 넘어, 경영진 및 마케팅 실무진이 **점포별·월별·상품군별·고객 등급별**로 다차원 교차 필터링을 수행할 수 있는 의사결정 지원 시스템(Decision Support System) 완성.
- 세계적인 웹 디자인 어워드인 **Awwwards 'Site of the Day' 수상작 [Neutomni](https://www.awwwards.com/sites/neutomni)**의 볼드 에디토리얼 & 레트로 미니멀 디자인 시스템을 벤치마킹하여 예술적 완성도와 시각적 몰입감을 극대화.

## 4. 핵심 개발 작업 상세

### 4.1 데이터 파이프라인 및 다차원 집계
- **입력 원천 데이터**:
  - `05_고객구매_데이터분석/data/customer_sales_data.csv` (10,000건 구매 내역)
  - `04_고객구매_데이터분석/고객별RFM_최종결과.csv` (2,333명 고객의 R/F/M 스코어 및 4개 등급)
- **다차원 레코드 설계**:
  - 조건 검색 시 10,000건의 행을 매번 브라우저에서 full-scan하는 대신, **[기준 월(1~12) × 점포(9곳) × 상품군(10개) × RFM 등급(4개)] = 총 4,290개 다차원 결합 블록**으로 전처리.
  - 레코드 필드 경량화:
    ```javascript
    { m: 1, st: "수원점", ch: "오프라인", cat: "소형가전", gr: "VIP 단골", sales: 8450000, refund: 120000, orders: 124, qty: 156, cust: 110 }
    ```
  - **효과**: 브라우저 메모리 부하 제로(700KB 단일 JS), 4가지 필터를 동시 변경해도 **0.01초 이내 실시간 리렌더링** 보장.

---

### 4.2 9회차 RFM 고객 가치 세그먼트 통합
- **4대 고객 세그먼트**:
  1. 👑 **VIP 단골** (고객 비중: 17.6% / 매출 기여도: 33.4%)
  2. ⭐ **우수 고객** (고객 비중: 28.1% / 매출 기여도: 36.0%)
  3. 👤 **일반 고객** (고객 비중: 24.7% / 매출 기여도: 18.2%)
  4. 💤 **휴면 고객** (고객 비중: 29.6% / 매출 기여도: 12.4%)
- **파레토 법칙(80/20 법칙)의 시각화**:
  - 상위 2개 등급(VIP + 우수 고객, 전체의 45.7%)이 **전체 매출의 69.4%(20.6억 원)**를 창출하는 구조를 도넛 차트 및 하단 요약 스트립(`rfm-summary-strip`)으로 직관적 제시.
  - VIP 고객의 평균 객단가(AOV)는 **₩52,344**로 일반 고객(₩25,830) 대비 **2배 이상** 높음을 실시간 반영.

### 4.3 HTML · CSS · JS 관심사 분리
- **HTML (`index.html`)**: 인라인 스타일을 일체 배제하고 W3C 시맨틱 태그(`header`, `section`, `article`, `table`, `footer`) 및 접근성 ARIA 레이블 엄격 준수.
- **CSS (`css/style.css`)**: 
  - CSS Custom Properties(`--variables`)를 통한 중앙 집중형 토큰 관리.
  - 반응형 CSS Grid & Flexbox, 알약(Pill) 쉐이프, 미세 그림자, `@media print` 인쇄 전용 스타일 시트 탑재.
- **JS (`js/app.js` & `js/data.js`)**:
  - 단일 상태 객체(`dashboardState`) 기반의 반응형 데이터 흐름.
  - Chart.js 인스턴스 라이프사이클 관리(`destroy()` 후 재생성으로 메모리 누수 방지).
  - 엑셀 한글 깨짐을 방지하는 UTF-8 BOM(`\uFEFF`) CSV 생성 엔진.

### 4.4 Awwwards SOTD 'Neutomni' 스타일 에디토리얼 리디자인
어워드 수상작인 **Neutomni**의 디자인 DNA를 대시보드에 녹여냈습니다.

```
[ Neutomni Design System Tokens ]
├── 캔버스 배경     : #F6F5F0 (따뜻한 미색 스톤 캔버스 + 미세 그리드 패턴)
├── 카드 배경       : #FFFFFF (선명한 화이트 카드 + 1px 솔리드 헤어라인)
├── 텍스트 잉크     : #141414 (깊이감 있는 딥 옵시디언 블랙)
├── 타이포그래피    : 'Inter Tight' (볼드 고딕) + 'Newsreader' (에디토리얼 세리프 이탤릭)
├── 시그니처 악센트 : #CF1830 (시나바 레드), #3EA094 (스튜디오 틸), #502BD8 (바이올렛)
└── 인터랙션 요소   : 45° 회전 다이아몬드 펄스 도트, 알약(Pill) 버튼, 모노스페이스 대괄호 태그
```

#### 🌟 시각적 주요 구현
1. **타이포그래피 교차 배치**:
   `장마트 경영 실적 <span class="editorial-italic">Dashboard</span>` 형태로 현대적 고딕과 우아한 세리프 이탤릭의 대비를 연출.
2. **다이아몬드 회전 펄스 뱃지**:
   ```css
   .pulse-dot {
     width: 7px;
     height: 7px;
     background-color: #CF1830;
     transform: rotate(45deg);
     display: inline-block;
     animation: neutomni-pulse 2s linear infinite;
   }
   @keyframes neutomni-pulse {
     0% { transform: rotate(45deg) scale(1); box-shadow: 0 0 0 0 rgba(207, 24, 48, 0.6); }
     50% { transform: rotate(90deg) scale(1.25); box-shadow: 0 0 0 5px rgba(207, 24, 48, 0); }
     100% { transform: rotate(135deg) scale(1); box-shadow: 0 0 0 0 rgba(207, 24, 48, 0); }
   }
   ```
3. **카드 인덱스 시스템**:
   카드 우측 상단에 `[ 01 ]`, `[ 02 ]`, `[ 03 ]` 등의 아카이브 인덱스를 배치하여 기술적 세련미 부여.
4. **차트 팔레트 조율**:
   기존 어두운 배경의 형광 차트를 백색 캔버스에 최적화된 시나바 레드 라인 차트, 스튜디오 틸 바 차트, 깔끔한 백색 절단선(white cutouts)이 들어간 도넛 차트로 변경.

### 4.5 실시간 상호작용 및 비즈니스 기능
1. **다차원 교차 필터링**:
   - 점포(온라인/오프라인 8개 지점), 기준 월(1~12월), 10개 상품군, 4개 RFM 고객 등급의 임의 조합 선택 가능.
2. **5대 핵심 KPI 카드 실시간 동기화**:
   - 조건부 총 매출액 (정상 매출 기준)
   - 총 주문 건수 및 판매 수량
   - 평균 객단가 (AOV: Average Order Value)
   - 합산 구매 고객수
   - 반품률(%) 및 온라인 매출 비중(%)
3. **엑셀 CSV 다운로드 기능**:
   - 필터링된 월별 집계 결과를 엑셀에서 한글 깨짐 없이 바로 열람 가능한 `\uFEFF` UTF-8 BOM 인코딩 적용.
4. **인쇄 및 PDF 보고서 최적화**:
   - `@media print` 쿼리를 적용하여 필터바, 내보내기 버튼, 새로고침 버튼 등 화면 제어 요소를 숨기고 A4 규격에 맞게 차트와 표만 깔끔하게 출력되도록 세팅.

## 6. 핵심 비즈니스 분석 인사이트

대시보드 데이터를 통해 도출된 장마트 2025 경영 전략 시사점입니다.

1. **하반기 연말 특수 폭발적 성장 (+90.1%)**:
   - 1월 1.84억 원에서 12월 3.51억 원으로 연중 최저치 대비 약 2배 가까이 매출 신장.
   - 4분기 집중 프로모션 및 시즌 상품(소형가전, 난방/침구류)의 매출 견인 효과 확인.
2. **VIP 단골의 높은 객단가와 충성도**:
   - VIP 단골의 평균 객단가는 **₩52,344**로 일반 고객(₩25,830)의 **2.03배**.
   - VIP 고객층 이탈 방지 프로그램(리텐션 마케팅)과 프라이빗 혜택 강화가 매출 방어의 핵심 열쇠.
3. **상품군별 매출-수량 포트폴리오 차별화**:
   - **매출 견인**: 소형가전(7.4억 원), 침구홈(4.6억 원) 등 객단가가 높은 고관여 카테고리가 총 매출의 40% 이상 차지.
   - **트래픽 및 빈도 견인**: 가공식품(1.9만 개), 신선식품(1.7만 개) 등 일상 식료품이 점포 방문 및 재구매 주기 유지의 중추 역할 수행.

## 7. 학습 요약 및 핵심 테이크어웨이 (Key Takeaways)

### 📚 1. 프론트엔드 아키텍처 (Front-end Architecture)
- **모놀리식에서 모듈러로**: 하나의 거대한 HTML 파일에 섞여 있던 CSS와 JS를 분리함으로써, 스타일 수정 시 스크립트를 건드릴 필요가 없어지고 유지보수성이 비약적으로 향상됨.
- **클라이언트 사이드 데이터 집계 최적화**: 10,000건의 로우 데이터를 매번 필터링하는 대신 차원별 집계 맵(Map) 구조를 사전 생성하여 저사양 디바이스에서도 렉 없이 동작하는 경량 아키텍처 완성.

### 🎨 2. 디자인 엔지니어링 (Design Engineering)
- **Awwwards급 디자인의 비결**: 화려한 3D 효과만이 정답이 아니며, **조화로운 컬러 팔레트(Warm Stone + Cinnabar Red), 정교한 타이포그래피(Serif Italic과 Grotesque의 조화), 1px 단위의 헤어라인과 여백(Padding), 절제된 마이크로 애니메이션**이 사이트의 품질을 완전히 다르게 만듦.
- **시각적 계층 구조(Visual Hierarchy)**: 대시보드의 특성상 수많은 숫자가 나열되므로, 모노스페이스 대괄호 태그(`[ 01 ]`), 선명한 KPI 레이블, 은은한 배경색 구분을 통해 사용자의 시선 피로도를 최소화함.

### ⚙️ 3. DevOps & 자동화 (DevOps & QA)
- **Git 버전 관리 & GitHub 연동**: 로컬에서 개발한 코드를 체계적인 커밋 메시지 규칙(`feat:`, `style:`, `refactor:`)에 따라 관리하고 원격 저장소에 즉시 동기화.
- **헤드리스 브라우저 테스트**: UI 변경 후 브라우저를 직접 띄우지 않고도 Python Selenium 스크립트를 통해 스크린샷을 자동 캡처하여 시각적 회귀(Visual Regression)를 즉시 검증하는 테스팅 기법 체득.
