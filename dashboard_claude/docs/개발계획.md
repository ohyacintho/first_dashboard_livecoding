### Task 2: 목표 계산·판정·요약 문장 (`targets.js`) (Opus 5.5 · high)

**Files:**
- Create: `dashboard_claude/targets.js`
- Modify: `dashboard_claude/tests.html`(테스트 추가, `targets.js` 불러오기), `dashboard_claude/index.html`(`targets.js`를 `script.js` 앞에)

**Interfaces:**
- Consumes: Task 1의 `JM.KPIS`, `JM.TARGET_FACTOR`, `JM.series`, `JM.fmt`, `JM.withUnit`
- Produces:
  - `JM.targetsFor(kpi, values: number[]) -> (number | null)[]` — 같은 길이. 인덱스 < 3 또는 직전 평균 ≤ 0이면 `null`
  - `JM.judge(kpi, actual: number, target: number | null) -> { level: 'good' | 'near' | 'bad', ratio: number | null, gap: number | null } | null` — target이 `null`이면 `null`. 높을수록 좋은 지표는 `ratio = actual / target * 100`, `gap = null`. 반품률은 `ratio = null`, `gap = actual - target`(%p)
  - `JM.LEVELS = { good: { icon: '✔', label: '달성' }, near: { icon: '△', label: '근접' }, bad: { icon: '✖', label: '미달' } }`
  - `JM.judgeText(kpi, j) -> string` — `'✔ 달성 105.1%'`, 반품률은 `'✖ 미달 0.39%p 초과'` / `'✔ 달성 0.10%p 여유'`(gap 절댓값 `toFixed(2)`)
  - `JM.targetText(kpi, target, monthIndex) -> string` — `'목표 3.28억 원'`(`withUnit(kpi, kpi.short(target))`), 반품률 `'목표 1.28% 이하'`, target `null`이면 monthIndex < 3일 때 `'목표 없음(4월부터)'`, 아니면 `'목표 없음'`
  - `JM.achievedCount(kpi, values) -> { hit: number, total: number }` — total은 목표가 있는 달 수
  - `JM.buildSummary(segName: string, month: number, v) -> string` — month는 1~12

**요약 문장 규칙** (값 = `withUnit(sales, sales.short(x))`, pct = `fmt.pctFloor1`)
- 4~12월 첫 문장(매출 판정별)
  - 달성: `{seg} {m}월 매출은 {값}으로 목표의 {pct}를 달성했어요.`
  - 근접: `{seg} {m}월 매출은 {값}으로 목표에 조금 못 미쳤어요(목표의 {pct}).`
  - 미달: `{seg} {m}월 매출은 {값}으로 목표의 {pct}에 그쳤어요.`
  - 매출 목표 없음: `{seg} {m}월 매출은 {값}이에요. 이번 달은 목표가 없어요.`
- 둘째 문장: 매출을 뺀 4개 중 판정이 달성이 아닌 지표를 `KPIS` 순서로 `, `로 잇는다. 목표 없는 지표는 뺀다.
  - 높을수록 좋은 지표 조각: `{label}{topic} 목표의 {pct}`
  - 반품률 조각: `반품률({실적 toFixed(2)}%)은 목표({목표 toFixed(2)}% 이하)를 넘었어요`
  - 끝맺음: 마지막 조각이 반품률이면 `.`, 아니면 `예요.`
  - 모두 달성: `나머지 지표도 모두 목표를 달성했어요.`
- 1월: `{seg} 1월 매출은 {값}이에요. 목표는 4월부터 계산돼요.`
- 2~3월: `{seg} {m}월 매출은 {값}으로 전월보다 {|증감률| toFixed(1)}% {늘었어요|줄었어요}. 목표는 4월부터 계산돼요.`
