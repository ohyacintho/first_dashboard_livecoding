# 장마트 대시보드 고도화 설계: 목표 대비 관리 + 공유 기능

> 작성: Claude (Anthropic) · 2026-10-17 · 대상 폴더 `dashboard_claude/`

## 1. 목적과 범위

**목적**: 팀장 보고·발표에 쓰는 월별 실적 화면. 실적이 목표를 달성했는지 한눈에 보이고, 링크·PDF·CSV로 나눌 수 있어야 한다.

**사용자가 정한 것**
- 고도화 방향: 목표 대비 관리, 발표·공유용 완성도
- 목표: 규칙으로 자동 계산 (직전 3개월 평균 × 1.05)
- 공유 기능 4개: 한 줄 요약, 주소로 화면 공유, 인쇄·PDF, CSV 내려받기
- 목표 표시 방식: 지금 화면(카드·차트·표)에 겹쳐 넣기
- HTML·CSS·JS만 사용, GitHub → Cloudflare Pages 정적 배포
- 생성 파일마다 Claude 작성 표시
- 작업 위치: `dashboard_claude/`만. `dashboard/`와 맨 위 폴더(다른 도구 작업물)는 건드리지 않는다.

**하지 않는 것**: 상품군·요일 분석, RFM 고객 분석, 목표 직접 입력, 테마 전환 버튼, 바깥 라이브러리.

## 2. 지표와 목표 규칙

### 2.1 지표 정의 (기존과 같음)

| 키 | 지표 | 계산 | 좋은 방향 |
|---|---|---|---|
| `sales` | 매출 | 정상(반품 제외) 총구매금액 합계 | 높을수록 |
| `customers` | 구매 고객 수 | 그 달 정상 거래 고객 수(중복 제외) | 높을수록 |
| `orders` | 주문 건수 | 정상 거래의 거래번호 수 | 높을수록 |
| `aov` | 객단가 | 매출 ÷ 주문 건수 | 높을수록 |
| `returnRate` | 반품률 | 반품 금액 ÷ (정상 + 반품) 금액 × 100 | 낮을수록 |

### 2.2 목표

- **목표(m월) = (m-3, m-2, m-1월 지표 값의 단순 평균) × 계수**
- 계수 기본값: `sales`, `customers`, `orders`, `aov` = **1.05**, `returnRate` = **0.95**
- 계수는 `kpis.js` 맨 위 한 곳에서 지표별로 바꿀 수 있다.
- 객단가·반품률도 "월별 비율 3개의 평균"으로 계산한다(합계로 다시 나누지 않는다).
- **1~3월은 목표 없음.** 직전 평균이 0 이하이면 그 달도 목표 없음.
- 점포 필터를 바꾸면 그 점포의 월별 값으로 같은 규칙을 적용한다.
- 목표 계산은 브라우저(`targets.js`)에서 `data.js`의 월별 값으로 한다. `build_data.py`와 `data.js` 형식은 바꾸지 않는다.

### 2.3 판정

| 지표 | 비교 값 | ✔ 달성 | △ 근접 | ✖ 미달 |
|---|---|---|---|---|
| 높을수록 좋은 4개 | 달성률 = 실적 ÷ 목표 × 100 | 100 이상 | 95 이상 100 미만 | 95 미만 |
| 반품률 | 실적과 목표(상한) | 실적 ≤ 목표 | 목표 < 실적 ≤ 목표 ÷ 0.95 | 그보다 높음 |

- 판정은 반올림하지 않은 값으로 한다.
- 화면의 달성률은 **소수 첫째 자리까지 내림**해 표시한다(예: 99.96% → 99.9%). 판정과 표시가 어긋나지 않게 하기 위해서다.
- 반품률은 달성률 대신 "목표 1.28% 이하 · 0.39%p 초과"(또는 "… 이하 · 0.10%p 여유")로 표시한다.
- 판정은 항상 기호 + 글자로 표시한다(✔ 달성 / △ 근접 / ✖ 미달). 색은 보조다.

### 2.4 기준값 (전체, 12월)

| 지표 | 실적 | 목표 | 판정 |
|---|---|---|---|
| 매출 | 344,868,700원 | 328,035,925원 | ✔ 105.1% |
| 구매 고객 수 | 4,684명 | 4,668.3명 | ✔ 100.3% |
| 객단가 | 50,294원 | 51,870원 | △ 96.9% |
| 반품률 | 1.67% | 1.28% 이하 | ✖ 0.39%p 초과 |

4~12월 판정 개수(전체): 매출 달성 8·근접 1, 고객 달성 6·근접 3, 주문 달성 9, 객단가 근접 6·미달 3, 반품률 달성 4·근접 1·미달 4.

## 3. 화면

### 3.1 맨 위
- 제목 오른쪽에 버튼 3개: `[링크 복사] [CSV] [인쇄]`. 520px 이하에서는 제목 아래로 내려간다.

### 3.2 한 줄 요약 (조회 조건 아래, 카드 위)
규칙으로 만드는 1~2문장. 첫 문장은 항상 매출이다.

- 4~12월
  - 1문장: "{점포} {m}월 매출은 {값}으로 목표의 {달성률}를 달성했어요." (근접: "…로 목표에 조금 못 미쳤어요.", 미달: "…에 그쳤어요.")
  - 2문장: 매출을 뺀 4개 중 달성하지 못한 지표를 순서대로 이어 쓴다. 예: "객단가는 목표의 96.9%, 반품률(1.67%)은 목표(1.28% 이하)를 넘었어요."
  - 4개 모두 달성: "나머지 지표도 모두 목표를 달성했어요."
- 1~3월: "{점포} {m}월 매출은 {값}으로 전월보다 {증감}. 목표는 4월부터 계산돼요." (1월은 증감 없이 "…{값}이에요.")
- 조사(은/는)는 지표 정의에 함께 적어 둔다.

### 3.3 KPI 카드
전월 대비 줄 아래에 목표 줄을 넣는다.
```
매출
3.45억 원
▲ 5.8% 전월 대비
✔ 달성 105.1% · 목표 3.28억 원
[12개월 흐름 선]
연간 합계 29.71억 원
```
1~3월은 "목표 없음(4월부터)".

### 3.4 월별 차트
- 4~12월 막대마다 목표를 짧은 가로 눈금(막대 폭 + 8px, 두께 2px, 짙은 회색 `--target`)으로 그린다.
- 오른쪽 위 범례: "■ 실적 ─ 목표" (반품률은 "─ 목표(상한)").
- 세로축 최댓값은 실적과 목표 중 큰 값으로 잡는다.
- 기준 월 값 라벨은 막대 끝과 목표 눈금 중 더 높은 쪽 위에 붙인다.
- 툴팁에 "목표 3.28억 원 · ✔ 달성 105.1%" 줄을 더한다.

### 3.5 월별 표
- 5개 지표 값 뒤에 판정 기호(✔△✖)를 붙인다. 화면 낭독기용 글자(달성·근접·미달)를 함께 넣는다.
- 맨 오른쪽에 **차트에 그린 지표**의 `목표`, `달성률` 두 열을 더한다.
- 바닥 두 줄: `연간`(연간 값, 목표 열은 "–"), `달성 개월`(지표별 "8/9". 분모는 목표가 있는 달 수).

### 3.6 색
- 새 토큰: `--target`(목표 눈금, 밝게 `#52514e` / 어둡게 `#c3c2b7`), `--warn`(근접 기호, `#fab219`, 글자는 `--text-1`).
- 달성 `--good`, 미달 `--bad`는 기존 토큰을 쓴다.

## 4. 공유 기능

### 4.1 주소로 화면 공유
- 상태를 주소 해시에 담는다: `#store=강남점&month=12&kpi=sales` (`URLSearchParams`로 읽고 쓴다).
- 상태가 바뀔 때마다 `history.replaceState`로 주소만 바꾼다(뒤로 가기 기록 없음).
- 처음 열 때, 그리고 `hashchange` 때 해시를 읽어 적용한다. 없는 점포, 1~12 밖의 월, 없는 지표는 각각 기본값(전체 / 12 / sales)으로 바꾼다.
- [링크 복사]: `navigator.clipboard.writeText(location.href)` 성공 시 버튼 옆에 "링크를 복사했어요"를 2초 표시. 실패하면 주소를 담은 읽기 전용 입력칸을 열고 전체 선택해 둔다.

### 4.2 CSV 내려받기
- 지금 고른 점포 기준. 행: 1~12월 + `연간`.
- 열 21개: `월`, 그리고 지표 5개마다 `{지표}`, `{지표} 목표`, `{지표} 달성률(%)`, `{지표} 판정`.
- 숫자 모양: 금액·명·건은 쉼표 없는 정수(반올림), 비율·달성률은 소수 둘째 자리. 목표 없는 칸은 비운다. `연간` 행의 판정 칸은 "달성 8/9개월".
- 파일 앞에 UTF-8 BOM(`﻿`)을 붙이고, 줄바꿈은 `\r\n`.
- 파일 이름: `장마트_실적_{점포}_2025.csv`. `Blob` + `a[download]`로 내려받는다.

### 4.3 인쇄·PDF
- [인쇄] = `window.print()`.
- `@page { size: A4 landscape; margin: 12mm; }`
- 1장: 제목·조회 조건 한 줄·요약·카드·차트. 2장: 월별 표(`break-before: page`).
- 버튼·선택 상자·툴팁은 숨기고, 대신 "조회 조건: {점포} · 2025년 {m}월 · {지표}"를 글자로 보여 준다.
- 다크 모드여도 인쇄는 밝은 토큰을 쓴다. 막대·기호 색은 `print-color-adjust: exact`로 유지한다.
- 차트 SVG는 `width: 100%; height: auto`로 종이 폭에 맞춘다(비율은 `viewBox`가 유지).
- 바닥글에 출력 날짜를 덧붙인다.

## 5. 파일 구성

일반 `<script>` 태그로 아래 순서대로 불러온다(ES 모듈은 더블클릭으로 연 파일에서 막히므로 쓰지 않는다). 파일끼리는 `window.JM` 하나로 주고받는다.

| 파일 | 하는 일 | 내놓는 것 |
|---|---|---|
| `data.js` | 월별 집계 숫자 (변경 없음) | `window.JANG_MART` |
| `kpis.js` | 지표 정의·숫자 모양·목표 계수 | `JM.KPIS`, `JM.TARGET_FACTOR`, `JM.fmt` |
| `targets.js` | 목표 계산·판정 (화면을 모름) | `JM.targetsFor(kpi, values)`, `JM.judge(kpi, actual, target)` |
| `share.js` | 주소 상태·링크 복사·CSV·인쇄 | `JM.readHash`, `JM.writeHash`, `JM.copyLink`, `JM.buildCsv`, `JM.downloadCsv` |
| `script.js` | 요약·카드·차트·표 그리기, 이벤트 연결 | 없음 (화면 진입점) |
| `tests.html` | 확인 항목 실행 페이지 | 통과·실패 목록 |

- `targets.js`와 `share.js`의 계산 함수(`buildCsv` 등)는 DOM에 손대지 않아 `tests.html`에서 바로 부를 수 있다.

- README에 새 파일과 목표 계수 바꾸는 법을 더한다.

## 6. 오류 처리
- `data.js`가 없으면 기존 안내 문구를 보여 준다.
- 해시 값이 잘못되면 기본값으로 바꾸고 주소도 고쳐 쓴다.
- 클립보드가 막히면 4.1의 입력칸으로 대신한다.
- 목표 없는 달은 "목표 없음" / "–" / 빈 칸으로 일관되게 표시한다.
