# 장마트 실적 모니터링 대시보드

> 작성: Claude (Anthropic)

장마트 2025년 구매 데이터(교육용 합성 데이터)로 만든 한 페이지 대시보드입니다.
핵심 지표 5개를 월별로 보고, 점포와 기준 월을 바꿔 가며 전월·목표와 비교합니다.

## 보여 주는 지표

| 지표 | 계산 방법 |
|---|---|
| 매출 | 반품을 뺀 총구매금액 합계 |
| 구매 고객 수 | 그 달에 한 번 이상 산 고객 수 (연간은 중복 제외) |
| 주문 건수 | 거래번호 수 |
| 객단가 | 매출 ÷ 주문 건수 |
| 반품률 | 반품 금액 ÷ (정상 + 반품) 금액, 낮을수록 좋음 |

## 화면 구성

- **조회 조건**: 점포(전체, 온라인몰, 오프라인 전체, 오프라인 8개 점포)와 기준 월
- **한 줄 요약**: 기준 월 매출이 목표를 달성했는지, 못 미친 지표는 무엇인지 글로 알려 줍니다
- **KPI 카드 5개**: 기준 월 값, 전월 대비 증감, 목표 달성 여부, 12개월 흐름(작은 선 그래프), 연간 값
- **월별 막대 차트**: 카드를 누르면 그 지표로 바뀌고, 막대를 누르면 기준 월이 바뀝니다. 4~12월 막대마다 목표 눈금이 함께 나옵니다
- **월별 상세 표**: 12개월과 연간 숫자, 판정 기호, 차트 지표의 목표·달성률을 보여 줍니다

## 목표 규칙

- **목표(m월) = 직전 3개월(m-3, m-2, m-1월) 값의 단순 평균 × 계수**
- 계수 기본값: 매출·구매 고객 수·주문 건수·객단가는 **1.05**(5% 더), 반품률은 **0.95**(5% 덜)
- **1~3월은 목표가 없습니다.** 직전 평균이 0 이하인 달도 목표가 없어요.
- 판정: 높을수록 좋은 지표는 달성률 100% 이상 ✔ 달성, 95% 이상 △ 근접, 그 미만 ✖ 미달. 반품률은 목표(상한) 이하면 ✔, 목표의 1/0.95배 이하면 △, 그보다 높으면 ✖ 입니다.
- 계수를 바꾸려면 `kpis.js`의 `TARGET_FACTOR`에서 지표별 숫자를 고치세요.

## 공유 기능

- **링크 복사**: 지금 고른 점포·기준 월·지표가 주소(`#store=…&month=…&kpi=…`)에 담겨 있어서, 복사한 링크를 열면 같은 화면이 나옵니다. 복사가 막히면 주소가 담긴 입력칸이 나와요.
- **CSV**: 지금 고른 점포의 1~12월과 연간 숫자(목표·달성률·판정 포함)를 내려받습니다. 엑셀에서 한글이 깨지지 않게 만들어 둔 파일이에요.
- **인쇄·PDF**: `인쇄` 버튼(또는 Ctrl+P)을 누르면 A4 가로 2장으로 나옵니다. 1장은 요약·카드·차트, 2장은 월별 표예요. 조회 조건과 출력 날짜가 글자로 들어가고, 어두운 모드여도 밝게 인쇄됩니다. PDF로 저장하려면 인쇄 창에서 대상을 'PDF로 저장'으로 고르세요.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대 (제목·설명은 여기서 고칩니다) |
| `style.css` | 색과 배치 (맨 위 색 값만 바꾸면 전체 색이 바뀝니다), 인쇄 모양 |
| `kpis.js` | 지표 정의, 숫자 모양, 목표 계수(`TARGET_FACTOR`) |
| `targets.js` | 목표 계산과 달성 판정 (화면을 건드리지 않는 계산만 있습니다) |
| `share.js` | 주소 상태 읽고 쓰기, 링크 복사, CSV 만들기·내려받기 |
| `script.js` | 요약·카드·차트·표 그리기, 버튼과 인쇄 연결 |
| `data.js` | 월별 집계 숫자 (`build_data.py`가 만든 파일) |
| `build_data.py` | `data/JANG_MART.csv`로 `data.js`를 다시 만드는 스크립트 |
| `tests.html` | 목표 계산·주소·CSV 확인 항목을 브라우저에서 돌려 보는 페이지 (`실패 0`이면 정상) |

바깥 라이브러리를 쓰지 않아서 `index.html`을 더블클릭하면 바로 열립니다.
원본 CSV는 올리지 않아도 됩니다. 화면은 `index.html`, `style.css`, 스크립트 파일들, `data.js`만 있으면 됩니다.

## 데이터 다시 만들기

CSV가 바뀌었을 때만 필요합니다. 이 폴더에서 실행하세요.

```bash
python build_data.py
```

## 웹에 올리기

1. GitHub 저장소에 이 폴더 **안의 파일들**을 올립니다. `index.html`이 저장소 맨 위에 있어야 합니다.
2. `docs/`(설계 문서)와 `tests.html`은 화면에 필요하지 않아서 올리지 않아도 됩니다.
3. Cloudflare Pages에서 저장소를 연결합니다. 빌드 과정이 없는 정적 사이트라 빌드 명령은 필요 없습니다.
