# 장마트 실적 모니터링 대시보드

> 작성: Claude (Anthropic)

장마트 2025년 구매 데이터(교육용 합성 데이터)로 만든 한 페이지 대시보드입니다.
핵심 지표 5개를 월별로 보고, 점포와 기준 월을 바꿔 가며 전월과 비교합니다.

## 보여 주는 지표

| 지표 | 계산 방법 |
|---|---|
| 매출 | 반품을 뺀 총구매금액 합계 |
| 구매 고객 수 | 그 달에 한 번 이상 산 고객 수 (연간은 중복 제외) |
| 주문 건수 | 거래번호 수 |
| 객단가 | 매출 ÷ 주문 건수 |
| 반품률 | 반품 금액 ÷ (정상 + 반품) 금액, 낮을수록 좋음 |

## 화면 구성

- **조회 조건**: 점포(전체, 온라인몰, 오프라인 전체, 오프라인 8개 점포)와 기준 월
- **KPI 카드 5개**: 기준 월 값, 전월 대비 증감, 12개월 흐름(작은 선 그래프), 연간 값
- **월별 막대 차트**: 카드를 누르면 그 지표로 바뀌고, 막대를 누르면 기준 월이 바뀝니다
- **월별 상세 표**: 12개월과 연간 숫자를 모두 보여 줍니다

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대 (제목·설명은 여기서 고칩니다) |
| `style.css` | 색과 배치 (맨 위 색 값만 바꾸면 전체 색이 바뀝니다) |
| `script.js` | 카드·차트·표 그리기 (맨 위 `KPIS` 목록이 지표 정의) |
| `data.js` | 월별 집계 숫자 (`build_data.py`가 만든 파일) |
| `build_data.py` | `data/JANG_MART.csv`로 `data.js`를 다시 만드는 스크립트 |

바깥 라이브러리를 쓰지 않아서 `index.html`을 더블클릭하면 바로 열립니다.
원본 CSV는 올리지 않아도 됩니다. 화면은 `data.js`만 있으면 됩니다.

## 데이터 다시 만들기

CSV가 바뀌었을 때만 필요합니다. 이 폴더에서 실행하세요.

```bash
python build_data.py
```

## 웹에 올리기

1. GitHub 저장소에 이 폴더 **안의 파일들**을 올립니다. `index.html`이 저장소 맨 위에 있어야 합니다.
2. Cloudflare Pages에서 저장소를 연결합니다. 빌드 과정이 없는 정적 사이트라 빌드 명령은 필요 없습니다.
