# 장마트 2025 실적 리포트 (Etsy 디자인 시스템 양식)

> 작성: Claude (Anthropic)

장마트 2025년 구매 데이터(교육용 합성 데이터, 90,681행)를 정리한 한 페이지 리포트입니다.
색·글꼴·모양은 오빠두 디자인 시스템 갤러리의 Etsy 토큰(오렌지 #F1641E, 따뜻한 베이지, 알약형 모서리, 세리프 제목)을 따랐습니다. Etsy 로고와 이름은 쓰지 않았습니다.

## 담은 내용

- 핵심 발견 4가지와 KPI 6개(순매출, 주문 건수, 구매 고객 수, 객단가, 반품률, 평균 할인율)
- 월별 추이(매출·주문 건수·구매 고객 수 전환)
- 상품군(매출·판매수량 전환), 채널과 점포, RFM 고객 등급
- 요일별 하루 평균 매출, 결제수단, 상품군별 반품률·할인율, 많이 팔린 상품 8개

문장 속 숫자도 모두 `data.js`에서 계산해서, 데이터를 다시 만들면 함께 바뀝니다.

## 파일

| 파일 | 하는 일 |
|---|---|
| `index.html` | 화면 뼈대 (제목·설명은 여기서 고칩니다) |
| `style.css` | 색과 배치 (맨 위 색 토큰만 바꾸면 전체 색이 바뀝니다) |
| `app.js` | 문장·카드·차트·목록 그리기 |
| `data.js` | 집계 숫자 (`build_data.py`가 만든 파일) |
| `build_data.py` | `data/JANG_MART.csv`와 `data/rfm_customers_backup.csv`로 `data.js`를 다시 만드는 스크립트 |

글꼴은 Google Fonts(Noto Sans KR, Noto Serif KR)를 불러오고, 인터넷이 없으면 기본 글꼴로 보입니다.

## 데이터 다시 만들기

```bash
python build_data.py
```
