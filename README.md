# 🛒 장마트(JANG MART) 2025 경영 실적 모니터링 대시보드 (고도화 버전)

2025년도 장마트 연간 구매 데이터를 기반으로 제작된 실무형 반응형 경영 실적 모니터링 웹 대시보드입니다.

---

## ✨ 고도화 신규 기능 (Option B)

1. **다차원 동적 필터바 (Multi-dimensional Dynamic Filters)**
   - **점포 선택**: 전체 / 온라인몰 전용 / 오프라인 전체 / 개별 8개 지점(수원, 잠실, 영등포 등)
   - **기준 월 선택**: 1~12월 전체 또는 특정 월 단일 선택
   - **상품군 선택**: 전체 또는 10대 카테고리(소형가전, 신선식품 등) 개별 선택
   - 필터 변경 시 상단 5대 KPI, 차트 4종, 하단 상세 테이블이 **실시간 즉시 재계산 및 렌더링**
2. **엑셀 호환 CSV 데이터 내보내기 (Export to CSV)**
   - 필터링된 조건의 월별 집계 데이터(매출, 반품, 주문수, 판매량, 객단가, 반품률)를 한글 엑셀 깨짐 없는 **UTF-8 BOM CSV 파일**로 즉시 다운로드
3. **인쇄 / PDF 리포트 최적화 (`@media print`)**
   - 상단 `인쇄 / PDF 저장` 버튼 클릭 시 보고서 전용 A4 가로 레이아웃으로 자동 정돈되어 출력
4. **월별 실적 상세 데이터 그리드 (Detailed Data Table)**
   - 월별 정상 매출액, 반품 금액, 주문 건수, 판매 수량, 객단가, 반품률 상세 표 제공
