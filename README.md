# 🛒 장마트(JANG MART) 2025 경영 실적 모니터링 대시보드

2025년도 장마트 연간 구매 데이터를 기반으로 제작된 반응형 경영 실적 모니터링 웹 대시보드입니다.

## 📌 주요 5대 핵심 실적 (KPI)

1. **연간 총 매출액**: `₩3,014,606,800` (약 30.1억 원)
2. **총 주문 건수**: `60,079건` (총 판매수량 121,493개)
3. **평균 객단가 (AOV)**: `₩50,177` (1인당 연평균 구매액 ₩301,461)
4. **구매 고객 수 및 재구매율**: `10,000명` (재구매율 `91.6%`, 1인당 연평균 6회 구매)
5. **온라인 채널 비중**: `39.6%` (온라인 11.9억 원 / 오프라인 18.2억 원)

## 📊 시각화 및 주요 기능

- **월별 실적 추이**: 1월~12월 매출액 및 주문건수 탭 전환 차트
- **옴니채널 비중**: 온라인몰 vs 오프라인 매장 매출 점유율 도넛 차트
- **상품군별 기여도**: 소형가전, 침구홈 등 10대 카테고리별 매출/수량 순위 전환 차트
- **오프라인 점포 Top 5**: 수원점, 잠실점, 영등포점 등 주요 거점 매장 매출 비교
- **반응형 디자인 & 다크 모드**: 데스크톱, 태블릿, 모바일 완벽 대응
